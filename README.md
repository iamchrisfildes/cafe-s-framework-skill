# CAFE(S) Context Review

`cafe-s-framework-skill` is an agent skill that reviews context written for AI agents, such as skill files, `AGENTS.md`, system prompts and specifications, against the five CAFE(S) properties: clarity, actionability, fidelity, efficiency and security. You run it on demand. It reports findings that cite lines, with no score.

The skill is under construction. Install and usage instructions come with the first release.

## Credit
